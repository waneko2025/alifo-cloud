# ALIFO Cloud v1.1

ALIFO専用クラウド。v1.0にログインとユーザー別保存領域を追加。

## 機能
- 新規アカウント作成
- ログイン / ログアウト
- ユーザーごとの保存領域
- ファイルアップロード / ダウンロード / 削除
- フォルダ作成 / 開く / 削除
- ドラッグ＆ドロップ
- PC / スマホ対応

## Render
Build Command:
npm install

Start Command:
npm start

## 重要
この版は試作版です。公開サービスとして本格運用する前に、Render等で永続ディスクを設定し、データベース、メール確認、パスワード再設定、レート制限、容量制限などを追加してください。
